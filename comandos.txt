para poder funcionar, instalar pacote angular:
* npm install -g @angular/cli

criar novo projeto:
ng new <project-name>

se quiser criar projeto com ssr
ng new <project-name> --ssr //confirmar para tirar a configuração 'prerender: true' pra evitar sustos

//////

//para criar componentes
ng generate

--para gerar componente 'user' (por padrão ele inicia na pasta 'app')
ng g c ../components/user

//para adicioanr eslint e prettier
compiar arquivos .prettierrc e eslint.config.mjs (projeto 99)
então
npm i --save-dev prettier

npm install --save-dev eslint@^9 @eslint/js@^9 typescript-eslint@^8 angular-eslint@^21 eslint-config-prettier eslint-plugin-import eslint-plugin-unused-imports

adicionar comandos:
    "lint": "eslint .",
    "lint:fix": "eslint . --fix"
